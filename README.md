# API Rest "Mudi" - Alura

Este foi o projeto implementado nos cursos **Spring MVC: crie um web app com Thymeleaf e Bootstrap** e **Spring MVC: autenticação com Spring Security, API Rest e AJAX**, para fixação do conteúdo, realizados na Alura Cursos Online.

O projeto consistiu na implementação de uma API Rest, simulando uma página de gerenciamento de pedidos de uma loja, a "Mudi". Foi implementado como prática do modelo MVC, utilizando camadas e desenvolvendo componentes como Controllers e Repositories. 

As camadas Model e Controller foram implementadas em Java, utilizando Spring Boot para inicialização e gerenciamento das dependências e o banco de dados utilizado foi o MariaDB. Foi experimentada a implementação de um login, com autorização e autenticação de usuário utilizando Spring Security.

A parte visual foi desenvolvida em sua maioria utilizando Thymeleaf e Bootstrap, aplicando conhecimentos de HTML, para elaboração das páginas da API de um modo mais bonito e claro.
